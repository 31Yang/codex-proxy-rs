# v3.26.2

## 修复与改进

- 修复 OpenAI `turn_rate_limit_exceeded` 被错误扩大为账号冷却的问题，保留原始错误和 `Retry-After`，由客户端按自身重试预算处理，避免后续请求在本地被挡成 `no_available_provider`
- OpenAI 明确返回 `503 + error.code=server_error` 时，在既有安全重放边界内进行有界重试，已交付正文或工具活动后不重放
- 修复 OpenAI 流式失败和 WebSocket 复用时重复写回旧 Cookie 的问题，并区分凭据版本冲突与存储故障
- OpenAI 账号预热改用模型目录支持的推理强度，避免因不支持的 `none` 导致预热失败
- 管理员登录分离访问凭据与续期凭据，访问凭据到期后可自动恢复；续期轮换支持短窗口内的并发与重试，并识别超出重试窗口的旧续期凭据重用
- 请求转储保留期支持正小数天数，例如 `0.5` 为 12 小时、`0.25` 为 6 小时，按已关闭分片的最后写入时间清理
- Windows 离线安装包优先解析 Microsoft Store，最多等待 30 秒后按架构回退到 OpenAI 官方包；修正包大小并按实际来源展示下载说明
- 账号批量编辑默认关闭调度，保存时始终应用界面显示的调度开关值；修复侧边栏键盘焦点环被裁切的问题

## 升级说明

- 已有单凭据登录会话保留到原期限，重新登录后获得新的自动续期能力
- `host.logging.request_dump_retention_days` 的默认值仍为 `1`，含义改为最近 24 小时；清理按分片进行，实际保存时间受最后写入时间和下次清理时机影响
