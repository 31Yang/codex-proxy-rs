# v3.24.1

## 修复与改进

- 修复管理观测查询超时或取消后过早释放 PostgreSQL 连接预算的问题；名额持续保留至数据库清理、事务回滚和连接归还完成，避免占用正常请求预留的连接容量
- 优化使用记录列表的精确计数和深分页：增加 Key 与账号筛选索引，从较近的索引端读取页面，第一页未填满时省去重复计数，保持筛选、总数和排序语义
- 使用统计查询失败时保留完整页面布局，顶部指标归零，各面板显示原有空状态，不再单独显示统计错误栏
- 为快照采集启用前缺失的历史 Key 名称和账号订阅增加一次性补偿；已有快照及启用后采集到的未知值保持不变，查询不增加实时配置关联

## 升级事项

- 数据库新增 `0029_usage_indexes_and_identity_snapshots.sql`，已发布的 `0001`–`0028` 保持不变。升级前备份数据库、停止旧版本写入并预留索引构建与历史补写时间；新增索引需要额外存储空间
- 历史名称与订阅取自补写时仍存在的配置，不保证等于请求发生时的值；已删除配置或无法补齐的字段保持未知
- 若源码部署已执行合并前未发布的 `0029` 或 `0030`，需单独处理迁移历史差异，不要修改 `_sqlx_migrations` 的 checksum 绕过校验
